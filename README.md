# FightVoicePro - 声控物语搏击音效插件

专用于声控物语的麦克风采集放大与搏击清晰音效插件（Tweak）。

## 功能特性

- **阶梯音量配置** - 新清晰500 / 旧清晰1000 / 超级战斗1500 三档固定增益
- **电台撕拉底噪** - 8kHz~16kHz 高频嘶嘶底噪 + 人声极度清晰带通滤波
- **关闭 AGC/降噪/AEC** - 释放电台高频底噪与声音动态
- **10段 EQ 精准调音** - 低频切除防闷 + 中高频齿音穿透 + 电台空腔感
- **悬浮控制面板** - 双指双击调出，可拖拽
- **手势冲突修复** - 列表区域滑动不触发浮窗拖动
- **常驻删除按钮** - 红色「删除」按钮直接删除，无需左滑
- **MP3 循环推流** - 通过 Zego 伴奏通道持续推送到房间麦克风
- **动态切换** - 开关实时生效，无需重新进房间

## 使用方法

1. 安装 `.deb` 或注入 `.dylib` 到声控物语 App
2. 启动 App 后，**双指双击**屏幕调出悬浮面板
3. 点击开关开启/关闭搏击音效
4. 拖拽浮窗可调整位置（列表区域滑动不会误拖动）
5. 音乐 Tab：点击「上麦发」推流，点击「删除」移除文件

## 音效档位

| 模式 | 增益 | 特征 |
|------|------|------|
| 新清晰搏击 | 500 | 高清齿音 + 轻微撕拉底噪 |
| 旧清晰搏击 | 1000 | 中度过载 + 电台撕拉感 |
| 超级战斗 | 1500 | 全频段极限爆音轰炸 |

## 构建

使用 Theos 构建：

```bash
make clean
make package FINALPACKAGE=1
```

输出文件位于 `packages/` 目录。

## 项目结构

```
├── Tweak.x                      # 核心 Hook 代码
├── Makefile                     # Theos 编译配置
├── control                      # deb 包控制文件
├── FightVoicePro.plist          # 注入过滤配置
└── .github/workflows/build.yml  # GitHub Actions 自动构建
```
