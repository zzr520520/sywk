# FightVoicePro v2.0.0 - 声控物语搏击音效插件

专用于声控物语的 PCM 底层音频拦截与机械撕裂搏击音效插件（Tweak）。

## v2.0.0 核心重构

- **PCM 底层帧拦截** - 直接 Hook `ZegoLiveRoomApi onCaptureAudioFrame:`，在麦克风采集的原始 PCM 数据帧上做实时修改，绕过所有上层 API 限制
- **MP3 解码注入** - 使用 `AVAssetReader` 将 MP3/WAV/m4a 解码为 44100Hz 单声道 16-bit PCM 内存池，直接混入麦克风采集帧，远端全房间可听
- **机械撕裂 DSP 算法** - 18Hz 极速脉冲断续切音 + 2400Hz 金属载波共振 + 暴力硬削顶过载失真，复刻直升机螺旋桨/极速破音电台效果
- **三档撕裂强度** - 新清晰(0.35) / 旧清晰(0.65) / 超级战斗(1.0)，每档独立增益与撕扯参数
- **效果音底噪混音** - 导入多个效果音文件，解码为 PCM 后按音量比例实时叠加到采集流

## 功能特性

- **PCM 帧级音频处理** - 底层 Hook 采集回调，所有音频修改在原始 PCM 数据上完成
- **MP3 → PCM 解码推流** - AVAssetReader 解码至内存池，逐采样混入麦克风帧，解决远端听不到问题
- **机械电台撕拉音效** - 18Hz 脉冲调制 + 2400Hz 载波共振 + 硬削顶失真
- **三档爆音模式** - 新清晰搏击(500) / 旧清晰搏击(1000) / 超级战斗(1500)
- **独立分档精细调节** - 调试页 5 个滑动条：新清晰/旧清晰/超级战斗音量 + 人声权重 + 效果音比例
- **多底噪自由切换** - 设置页支持导入多个底噪文件，点击「选用」切换，再点取消
- **强制关闭系统 3A** - AGC/降噪/AEC 全部关闭，释放撕拉高频底噪与声音动态
- **悬浮控制面板** - 双指双击调出，可拖拽
- **手势冲突修复** - 列表/调试区域滑动不触发浮窗拖动
- **常驻删除按钮** - 红色「删除」按钮直接删除，无需左滑
- **iOS 13+ 兼容** - 使用 UIWindowScene 获取 keyWindow
- **动态切换** - 开关实时生效，无需重新进房间

## 使用方法

1. 安装 `.deb` 或注入 `.dylib` 到声控物语 App
2. 启动 App 后，**双指双击**屏幕调出悬浮面板
3. 点击开关开启/关闭搏击音效
4. 拖拽浮窗可调整位置（列表区域滑动不会误拖动）
5. **音乐 Tab**：点击「上麦发」解码 MP3 至 PCM 并注入推流，点击「删除」移除文件
6. **设置 Tab**：导入多个底噪 MP3/WAV，点击「选用」切换，再点「使用中」取消
7. **调试 Tab**：独立调节各档位音量、人声权重、效果音比例

## 音效档位

| 模式 | 默认增益 | 调节范围 | 撕裂强度 | 特征 |
|------|----------|----------|----------|------|
| 新清晰搏击 | 500 | 100~1000 | 0.35 | 高清齿音 + 轻微撕拉底噪 |
| 旧清晰搏击 | 1000 | 500~2000 | 0.65 | 中度过载 + 电台撕拉感 |
| 超级战斗 | 1500 | 1000~3000 | 1.0 | 全频段极限爆音轰炸 |

## DSP 算法参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 脉冲调制频率 | 18 Hz | 极速电台断续切音频率 |
| 载波频率 | 2400 Hz | 机械撕拉金属共振频率 |
| 采样率 | 44100 Hz | PCM 解码目标采样率 |
| 位深 | 16-bit | 线性 PCM |
| 声道 | 单声道 | Mono |

## 调试参数

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 人声音量权重 | 1.0 | 0.5~2.0 | 叠加在基础增益上的倍率 |
| 效果音推流音量 | 60 | 10~100 | 效果音推向远端的音量 |

## 构建

使用 Theos 构建：

```bash
make clean
make package FINALPACKAGE=1
```

输出文件位于 `packages/` 目录。

## 项目结构

