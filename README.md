# FightVoicePro v15.0.0 - 终极炸裂版：电锯撕裂 + 方波地震冲击波

在完整保留原有所有开关、滑块、结构与通道的基础上，整合「斜率陡增撕裂算法」与「纯方波地震冲击波」。

## v15.0.0 核心升级

### 三层效果架构

| 层级 | 模块 | 说明 |
|------|------|------|
| 第1层 | 原生 API 主控 | setCaptureVolume (至5000) + 10段EQ + 关3A + 128k码率 |
| 第2层 | 核心撕裂层 | 0.85阈值斜率陡增2.2倍 + 85%极高密度湿声覆盖 |
| 第3层 | AUX混音通道 | 58Hz纯方波亚低频地震冲击波 + 116Hz磁力方波 |

### 核心撕裂算法

```
人声输入
  │
  ├─ 噪声门限 (gateThreshold 0.007)
  │   └─ 静音时绝对干净
  │
  ├─ 双二阶 EQ (2.8kHz +14dB / 120Hz +8dB)
  │
  ├─ 侧链压缩 (threshold 0.040, invRatio 0.066)
  │
  ├─ 极限补偿增益 (7.5 × drive)
  │   └─ 强制推动波形进入硬削波区
  │
  ├─ 谐波激励器 (ApplyHyperExciter)
  │   └─ x + 0.22x|x| + 0.05x|x|x
  │
  ├─ 【核心撕裂】斜率陡增
  │   ├─ 超过 +0.85 → 斜率 ×2.2
  │   └─ 超过 -0.85 → 斜率 ×2.2
  │   └─ 制造金属刮擦撕裂感
  │
  ├─ 湿/干混音 (85% 撕裂湿声 + 15% 原始干声)
  │
  └─ 硬截断 (±32767) → 产生方波冲击
```
