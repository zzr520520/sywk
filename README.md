内置 Studio One 专业机架效果链：动态人声联动磁力电流冲击波发生器 + 58Hz 亚低频轰炸 + Saturn 2 电子管磁力饱和 + 5000 极限声压 + 4000 冲击波能量 + 128kbps 全频带 + 双声道立体声 + 10 段机架 EQ + 噪声门静音。

## v13.0.0 核心升级 — 磁力电流冲击波轰炸链

### 效果链架构（复刻 Studio One 机架工程）

```
人声输入
  │
  ├─ 1. 噪声门限 (Pro-G Gate)
  │   └─ 不说话时绝对静音，一开口极速触发
  │
  ├─ 2. 动态联动冲击波发生器
  │   ├─ 58Hz 亚低频正弦冲击波 (4000 档位能量)
  │   └─ 116Hz 磁力电流共振脉冲
  │
  ├─ 3. 机架 EQ (Pro-Q3)
  │   ├─ 80Hz 冲击波能量 +12dB (Q=1.2)
  │   └─ 2.8kHz 穿透咬字 +16dB (Q=1.0)
  │
  ├─ 4. 磁力电流饱和 (Saturn 2)
  │   ├─ 非对称电子管软击穿
  │   └─ 偶次磁力泛音注入
  │
  ├─ 5. 双轨混音
  │   ├─ 人声主轨: 5000 极限声压 (0.75 混音比)
  │   └─ 冲击波底轨: 4000 能量 (0.55 混音比)
  │
  └─ 6. 软限幅 (Pro-L2)
      └─ 封顶 0.985 防爆音，0.995 硬限
```

### 底层生成原理

| 原理 | 说明 |
|------|------|
| 动态联动触发 | 不说话时噪声门保持静音，一开口包络检测器瞬间打开，联动激活冲击波 |
| 电流磁力饱和 | 人声经过非对称电子管软击穿，包裹"滋滋带电"的高能量磁场电流声 |
| 双轨叠加 | 冲击波底轨 4000 档位 + 人声主轨 5000 封顶满格，形成绝对压制感 |

### HUD 控制面板

**功能页开关**：

| 开关 | 默认 | 说明 |
|------|------|------|
| 强制开麦 (防静音) | ON | 防止被静音/下麦 |
| 动态磁力冲击波 | ON | 冲击波总开关 |
| 5000+4000 轰炸模式 | ON | 磁力电流冲击波轰炸模式 |

**参数页滑块**：

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 冲击波能量 | 1000 ~ 6000 | 4000 | 58Hz 亚低频冲击波强度 |
| 人声主轨增益 | 1.0 ~ 3.0 | 1.6 | 人声 5000 级极限声压 |
| 磁力电流饱和度 | 1.0 ~ 4.0 | 2.2 | Saturn 2 电子管驱动强度 |

### 使用方法

1. 安装 `.deb` 或注入 `.dylib` 到声控物语 App
2. 进房开麦
3. **双指双击**屏幕调出 HUD 面板
4. 确认「5000+4000 轰炸模式」已开启
5. 参数页可实时调节冲击波能量、人声增益、磁力饱和度

### 体验效果

- **安静时不说话**：噪声门保持绝对干净静音，没有丝毫底噪电流
- **只要一开口**：
  - 58Hz 亚低频冲击波 (4000 级) 瞬间触发，带强烈胸腔轰鸣
  - 人声裹挟磁力电流软饱和 (5000 级)，中高频 2.8kHz/4kHz 顶格刺穿
  - 整体听感呈现 Studio One 专业机架声卡的"电流冲击波轰炸"质感
