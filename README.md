# FightVoicePro - 声控物语搏击音效插件

专用于声控物语的麦克风采集放大与搏击清晰音效插件（Tweak）。

## 功能特性

- **纯 SDK 远端推流** - 彻底放弃 AVAudioPlayer，统一使用 ZegoMediaPlayer 的 setAudioStreamType:2 + setProcessType:0 伴奏推流混音模式，远端全房间可听
- **海浪杂音消除** - 31Hz 切除 -12dB、62Hz 切除 -6dB，消除超低频空腔轰鸣
- **多底噪自由切换** - 设置页支持导入多个底噪文件，点击「选用」切换，再点取消
- **效果音伴随推流** - 说话/开麦时自动循环混入选中底噪，停止推流时自动停止
- **独立分档精细调节** - 调试页 5 个滑动条：新清晰/旧清晰/超级战斗音量 + 人声权重 + 效果音比例
- **阶梯音量配置** - 新清晰500 / 旧清晰1000 / 超级战斗1500 三档固定增益
- **电台撕拉底噪** - 2kHz~8kHz 高频嘶嘶底噪 + 人声极度清晰带通滤波
- **关闭 AGC/降噪/AEC** - 释放电台高频底噪与声音动态
- **悬浮控制面板** - 双指双击调出，可拖拽
- **手势冲突修复** - 列表/调试区域滑动不触发浮窗拖动
- **常驻删除按钮** - 红色「删除」按钮直接删除，无需左滑
- **动态切换** - 开关实时生效，无需重新进房间

## 使用方法

1. 安装 `.deb` 或注入 `.dylib` 到声控物语 App
2. 启动 App 后，**双指双击**屏幕调出悬浮面板
3. 点击开关开启/关闭搏击音效
4. 拖拽浮窗可调整位置（列表区域滑动不会误拖动）
5. **音乐 Tab**：点击「上麦发」纯 SDK 推流到远端，点击「删除」移除文件
6. **设置 Tab**：导入多个底噪 MP3/WAV，点击「选用」切换，再点「使用中」取消
7. **调试 Tab**：独立调节各档位音量、人声权重、效果音比例

## 音效档位

| 模式 | 默认增益 | 调节范围 | 特征 |
|------|----------|----------|------|
| 新清晰搏击 | 500 | 100~1000 | 高清齿音 + 轻微撕拉底噪 |
| 旧清晰搏击 | 1000 | 500~2000 | 中度过载 + 电台撕拉感 |
| 超级战斗 | 1500 | 1000~3000 | 全频段极限爆音轰炸 |

## 调试参数

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 人声音量权重 | 1.0 | 0.5~2.0 | 叠加在基础增益上的倍率 |
| 效果音推流音量 | 50 | 10~100 | 效果音推向远端的音量 |

## 构建

使用 Theos 构建：

```bash
make clean
make package FINALPACKAGE=1
```

输出文件位于 `packages/` 目录。
